Arraste as estrelas e ligue os pontos. Depois copie o código pronto para seu jogo Word! no GameMaker.

1. Escolha a fase

Estrela selecionada

Clique em uma estrela para ajustar seu brilho.

Como editar: use Mover para arrastar estrelas, Adicionar para criar pontos, Ligar para clicar em duas estrelas e traçar uma linha, e Apagar para remover uma estrela ou linha.
IMPORTANTE: esta página funciona localmente, sem internet, mas não altera o GameMaker sozinha. Use Gerar código GML e cole no script do projeto. Para continuar editando em outro dia, salve seu desenho em JSON.

Dica: comece pelos pontos do contorno, conecte-os e depois adicione detalhes internos. O jogo anima tudo automaticamente.

As coordenadas variam de 0,00 a 1,00.
